# Pruebas transversales

- `backend/src/test/`: unitarias y de aplicación Java.
- `frontend/src/test/`: pruebas de contratos y componentes React.
- `tests/e2e/`: pruebas integradas futuras (navegador + API + PostgreSQL) y evidencia.

El tester define escenarios antes del desarrollo, ejecuta regresión antes de fusionar y mantiene trazabilidad RF → CU → test → evidencia.
