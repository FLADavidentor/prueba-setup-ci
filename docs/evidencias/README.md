# Evidencias verificables

Registrar por issue o PR: versión de GitHub, fecha, pasos de reproducción, resultado esperado y real, capturas **sin datos personales** y responsable de revisión. Preferir enlazar evidencias almacenadas en el sistema del curso cuando el archivo sea grande o sensible.

No subir capturas con contraseñas, datos de alumnos, respuestas personales ni información de salud.
