# Módulo BFA - Sprint 1

Agregar componentes y páginas de BFA aquí, **sin duplicar** el diseño, el cliente HTTP, los DTOs o los componentes reutilizables.

Para comenzar, se necesitan DOC-02 (requisitos), DOC-03 (modelo), DOC-04 (casos de uso), DOC-05 (API) y reglas de puntuación aprobadas. No utilizar fórmulas inferidas ni datos personales de ejemplo.

La primera historia puede implementar dos componentes y dos pantallas, según el mockup, pero sus comportamientos y criterios de aceptación deben formalizarse antes de declarar terminado el sprint.
